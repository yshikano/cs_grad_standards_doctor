# 筑波大学達成度評価シート入力・確認支援（非公式）
## 情報理工学位プログラム（博士後期課程）用

GitHub Pages 上で動作する、博士後期課程向けの達成度評価シート入力・確認支援アプリです。

## 主な機能

- **3 モード**
  - 履修計画
  - D中間評価
  - D最終評価
- **日本語 / English 切替**
  - 画面上部の `Language` ボタンで切替
  - 日本語表示時は `D中間評価`, `D最終評価`
  - 英語表示時は `D Mid-term evaluation`, `D final evaluation`
- **授業検索**
  - `data/kdb-grad.json` に入っている大学院開設授業科目を検索
  - システム情報工学研究群の博士後期課程向け公式配点つき科目は初期配点を優先
- **固定欄対応**
  - 11行: 情報理工後期特別研究
  - 12行: 情報理工後期特別演習A
  - 13行: 情報理工分野横断後期特別演習
  - 通常科目は 14 行目以降へ配置
- **授業科目以外**
  - 論文・発表
  - 特許
  - 研究室 WG
  - CS スペシャルワークショップ
  - 学位プログラム外活動
  - TA
  - TOEIC / TOEFL
  - INFOSS / APRIN
  - 自由入力
- **確認タブ**
  - 必要点を満たしていない観点を表示
  - システム情報工学研究群外の科目を別途確認対象として表示
- **時間割プレビュー**
  - `data/kdb-grad.json` に基づく簡易表示
  - `集中` はリスト表示

## データ構成

- `data/kdb-grad.json`
  - 大学院開設授業科目一覧の検索母集団
- `data/d-courses.sample.json`
  - 博士後期課程の情報理工学位プログラム向け公式配点つき科目データ

## 使い方

1. このフォルダ一式を GitHub リポジトリに置く
2. GitHub Pages を有効化する
3. `Achievement-Evaluation-Sheet（D-2024-Enrollees）.xlsx` を読み込む
4. `Language` ボタンで必要に応じて日本語 / English を切り替える
5. 履修計画 / D中間評価 / D最終評価 を切り替えながら入力する
6. 必要なら `確認` タブで未達観点と別途確認科目を見る
7. 最後に `現在のモードを Excel に一括反映` を押して、更新済み Excel をダウンロードする

## 配置前提

このアプリは同じリポジトリ内の次の配置を前提にしています。

- `index.html`
- `app.js`
- `styles.css`
- `.nojekyll`
- `data/kdb-grad.json`
- `data/d-courses.sample.json`

## 注意

- `xlsx-populate` は CDN から読み込みます。
- GitHub Pages 上では `.nojekyll` を同梱してあります。
- 非公式ツールです。最終的な配点の妥当性は指導教員・副指導教員と確認してください。
